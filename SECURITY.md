# Security

For vulnerabilities that may expose documents, compromise the local machine or bypass the offline boundary, please use GitHub's [private vulnerability reporting](../../security/advisories/new) feature. Please do not post private documents, full logs or credentials in public issues.

PDF processing handles untrusted complex files and runs external local processes. Keep the application and dependencies updated and treat files from unknown sources with care. The local application logs may contain document fragments and paths. No response-time guarantee is implied.
